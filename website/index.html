The private computer-use agent

Agent S is fully open source. Run a model on your own computer and give your agent a private sandbox for code, the web, and desktop apps.

Download for Mac Build from source

Apple Silicon · macOS 14 or later Windows coming soon

Fully private on your device

On macOS, pair a local Ollama model with the Linux sandbox to keep inference and desktop execution on your device.

On-device inference

The local model processes prompts, screenshots, and tool output on your computer. Chats are saved locally, and you choose which installed model to run.

A separate desktop

The agent works in its own Linux environment, separate from your everyday apps and files. Use the shared folder to give it files, and watch or take over its desktop at any time.

Websites the agent visits still receive ordinary browser traffic. Permissions and data

A sandbox with a full desktop

Give Agent S a task in plain language. It can use the terminal, browser, and desktop together.

Run code

Write and run scripts, use terminal tools, and process files inside the sandbox.

Browse the web

Navigate sites in Chromium, fill forms, and collect information.

Use desktop apps

Open Linux apps and work in them by clicking, typing, and scrolling.

Optional cloud tools

Choose hosted inference, a remote sandbox, or both when the task calls for it.

OpenRouter with ZDR

Use hosted models through OpenRouter and request Zero Data Retention routing. The model processes requests off-device, and retention follows your OpenRouter privacy settings.

OpenRouter’s ZDR policy

Remote sandbox with Simular Box

Move work to a cloud Linux desktop with a browser, shell, and files. Box can group several desktop actions into one tool call, reducing model round trips.
