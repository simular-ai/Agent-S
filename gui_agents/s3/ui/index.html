Configuration

1 · Planner (chat model)

Vision-capable chat model. LM Studio default: http://localhost:1234/v1, key lm-studio. Choose codex to use your ChatGPT/Codex subscription through the Codex SDK.

Codex status unknown.

2 · Grounding (UI-TARS)

Locates UI elements → x,y pixels. Serve UI-TARS-1.5-7B in LM Studio (or any hosted UI-TARS endpoint). Width/height must match the model: 7B → 1920×1080.

3 · Agent behaviour

Blank API keys retain saved credentials or use provider environment variables. Changing provider clears its saved key. The overlay stays hidden through capture and execution. A manual coding-agent approval covers the entire coding-agent invocation.

OpenAI-compatible API

This server is itself OpenAI-compatible. Point any OpenAI client at /v1:

curl http://127.0.0.1:8000/v1/models curl http://127.0.0.1:8000/v1/chat/completions -H "Authorization: Bearer $AGENT_S_UI_TOKEN" -H "Content-Type: application/json" -d '{"model":"agent-s3","messages":[{"role":"user","content":"Open notepad and type hello"}]}' # uses the saved execution mode; manual mode requires /api/tasks import os from openai import OpenAI c = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key=os.environ["AGENT_S_UI_TOKEN"]) print(c.models.list()) # planner + grounding + agent-s3 print(c.chat.completions.create(model="gpt-x", messages=[{"role":"user","content":"hi"}]).choices[0].message.content) # proxied to planner/LM Studio
